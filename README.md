# Space Shooter 2D game
A 2D space shooter game made with the Godot Engine.

## Features
* Control the player spaceship.
* Shoot enemy spaceship.
* Enemies can be spawned during the game.
* A game over screen is shown when the player loses.

## Most common commands 
* Use of Godot scenes and nodes.
* Use of GDScript.
* Use of signals and collision detection.
* Use of variables, functions and conditional logic.

## How to run it
* Download the .exe in the assets section.
* Then double click on the file and play.

 ## What I learned
 * Basics of the Godot Engine.
 * Creating and using scenes and nodes.
 * Writing scripts using GDScript.
 * Player movement and input handling.
 * Collision detection.
 * Creating and spawning enemies.
